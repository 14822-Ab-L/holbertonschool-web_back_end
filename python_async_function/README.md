# Python - Async

This directory contains Python exercises focused on asynchronous programming using coroutines and the `asyncio` module.

## Topics

- Asynchronous programming
- `async` and `await`
- Coroutines
- Executing asynchronous functions
- Concurrent execution
- Creating asyncio tasks
- Measuring execution time
- Random delays

## Files and Description

| **File** | **Description** |
|---|---|
| `0-basic_async_syntax.py` | Defines an asynchronous coroutine that waits for a random delay and returns it. |
| `1-concurrent_coroutines.py` | Executes multiple coroutines concurrently and returns their delays in ascending order. |
| `2-measure_runtime.py` | Measures the execution time of concurrent coroutines and calculates the average runtime. |
| `3-tasks.py` | Creates and returns an asyncio task for the `wait_random` coroutine. |
| `4-tasks.py` | Executes multiple asyncio tasks concurrently and returns their delays in ascending order. |
