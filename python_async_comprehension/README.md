# Python - Async Comprehension

This directory contains Python exercises focused on asynchronous generators and comprehensions using the `asyncio` module.

## Topics

- Asynchronous generators
- `async` and `await`
- `yield`
- Async comprehensions
- Asynchronous iteration
- Concurrent execution
- Measuring execution time
- Random number generation

## Files and Description

| **File**                    | **Description**                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------- |
| `0-async_generator.py`      | Defines an asynchronous generator that yields 10 random numbers with a 1-second delay. |
| `1-async_comprehension.py`  | Collects 10 random numbers from an asynchronous generator using an async comprehension. |
| `2-measure_runtime.py`      | Measures the execution time of four asynchronous comprehensions running concurrently. |
